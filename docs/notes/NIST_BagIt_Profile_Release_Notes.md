# NIST BagIt Profile: Release Notes

This document summarizes changes to the
[NIST profile](https://ui.adsabs.harvard.edu/abs/2019ASPC..523..295P/abstract) on the
[BagIt standard](https://tools.ietf.org/html/rfc8493) used as a preservation format for
publications to the NIST Public Data Repository (PDR). 

## Version 0.2

Earliest version used by the PDR.

## Version 0.4

Switched to use of version 0.4 of the Multbag profile.  In use to at least 2026.

## Version 0.5

Dropping requirement for including POD metadata file (pod.json).  Switch to DCAT 3
planned for v0.6
